## 무엇을 만드나

**IUEM(이음)** 은 AI가 만든 곡으로 하는 노래·연주 챌린지다.

1. 운영자가 Suno 로 만든 곡을 올린다.
2. 사용자는 곡을 듣고 **똑같이 부르거나 연주한다.** 퍼펙트싱어처럼 음정·박자가 맞는지 화면에서 바로 보인다.
3. 끝나면 점수가 나오고 **랭킹에 자연스럽게 오른다.** AI 가 무엇을 고칠지 짚어 주고 다음에 부를 곡을 고른다.

## 사용자가 보는 화면

| 화면 | 주소 | 내용 |
|:--|:--|:--|
| 홈 | `/` | 핵심 흐름, 지금 도전할 곡, 내 진척도, 이번 주 스타(주간 랭킹) |
| 챌린지 목록 | `/music-challenge` | 곡 카드. 이미 부른 곡에는 "도전한 곡" 표시 |
| 챌린지 상세 | `/music-challenge/[id]` | 원곡 듣기, 노래방 모드 입구, 곡별 랭킹, 간단 제출(녹음·파일) |
| 노래방 · 연주 | `/music-challenge/[id]/play` | 흘러오는 음표, 내 음정 선, 실시간 점수·콤보·판정, 가사, 싱크 보정 |
| 내 기록 | `/music-challenge/me` | 총 도전 · 평균 · 최고 점수, 점수 추이 |
| 악보 스튜디오 (관리자) | `/music-challenge/[id]/studio` | 스템 업로드 → 정답 멜로디 피아노 롤, 가사 붙여넣기, Space 로 줄 타이밍 |

## 채점 규칙

화면과 서버가 **같은 규칙**을 쓴다. 랭킹에는 조작할 수 없는 서버 점수만 오른다.

- **옥타브는 따지지 않는다.** 남자가 여자 노래를 한 옥타브 낮게 불러도 정답이다.
- **음정** — 정답에서 ±50센트 안이면 온전히, ±100센트 안이면 절반만 인정한다.
- **박자** — 음표가 시작되고 0.2초 안에 맞는 음을 내기 시작하면 제때 들어간 것이다.
- **음표 점수** = 음정 75% + 박자 25%. 긴 음표일수록 전체 점수에 크게 반영된다.
- 판정 등급: PERFECT ≥ 90 · GREAT ≥ 70 · GOOD ≥ 40 · 그 아래 MISS. 콤보는 MISS 에서 끊긴다.

## 노래 · 연주곡

정답 멜로디는 두 방식으로 뽑는다.

| | 노래 (보컬) | 연주곡 (악기) |
|:--|:--|:--|
| 정답을 뽑는 트랙 | 보컬 스템 | 멜로디 악기 하나의 스템 |
| 음역 | C2 ~ C6 | C2 ~ C7 |
| 음표를 끊는 기준 | 음높이가 0.7반음 넘게 바뀔 때 | 음높이 + **건반·줄을 새로 친 순간** |
| 후처리 | 끌어올리기 조각 합치기, 튀는 음 교정 | 없음 (트릴이 뭉개지므로) |
| 가사 | 있음 | 없음 |

한계도 적어 둔다. 한 번에 한 음만 잡으므로 **화음은 판정하지 않는다.** 악보가 공개돼 있어
악보대로 합성한 "완벽한 연주"를 제출하면 가려내지 못한다.
