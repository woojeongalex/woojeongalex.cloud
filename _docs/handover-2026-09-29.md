## 4. 알려진 함정

- **하네스 문서가 틀렸다**: `alexview/CLAUDE.md` 의 `pnpm lint:fix` · `pnpm format` 은 **존재하지 않는 스크립트**다. eslint 도 설치돼 있지 않다. 실제로 도는 건 `pnpm type-check` 뿐
- **ruff·mypy 위치**: PATH 에 없다. `~/.venvs/lint/bin/ruff`, `~/.venvs/lint/bin/mypy` 를 쓴다
- **mypy 전체 실행 불가**: `alembic`/`apps` 중복 모듈 오류로 멈춘다. 파일을 지정해 돌린다. 기존 14건(SQLModel `table=True` 등)은 예전부터 있던 것
- **`pgrep -f "이름"` 으로 종료를 기다리지 말 것**: 감싸는 bash 자신의 명령줄이 걸려 무한 대기한다. 9/28 에 두 번 당했다(`prepare_song.py` 대기, `pkill -f "next dev"` 가 자기 셸을 죽임)
- **HMR 이 안 먹는다**(`/mnt/c` 라서): 코드를 고치면 `.next` 지우고 dev 서버를 다시 띄워야 한다. `.next` 의 생성 타입이 낡으면 `pnpm type-check` 가 없는 파일을 찾는다며 실패한다
- **느리다는 말엔 측정부터**: 9/28 성능 문제 4건이 전부 코드가 아니었다(Cloudflare 엣지, WAV 크기, 스왑). `free -h` 의 Swap used 부터 본다
- **디스크**: 실제 Docker 는 WSL 안(C 드라이브)이다. D 의 Docker Desktop 이 아니다. 빌드 전에 C 여유를 확인한다
